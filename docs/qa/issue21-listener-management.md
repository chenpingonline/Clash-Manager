# Issue #21 补充问题：入口管理优化

日期：2026-11-01。此记录覆盖 Clash-Manager 工作目录中的未发布改动。

## 实现与兼容

- `core-user-settings.json` 的 `manager-independent-profiles` 按配置 ID 保存总开关和入口列表；配置合成显式传入作用域，管理记录不会进入 Mihomo YAML。
- 旧全局列表只迁移一次，归属迁移前的当前配置。没有可靠归属的旧入口保留待分配，显式添加到指定配置后默认停用。UDP 未指定时沿用旧行为：Mixed/SOCKS5 开启，HTTP 关闭。
- 当前配置保存继续使用原有 prepare/activate/commit/rollback 流程；未应用配置仅检查结构、名称和配置内端口冲突并保存偏好，不探测实际端口、不写运行配置、不创建激活事务。
- 关闭总开关保留逐条启用意图，仅清理托管入口；订阅自带 listeners 保留。停用或缺失目标的入口不参与订阅名称冲突检查。
- 新增入口列表、搜索、批量操作、复制、名称填充、端口分配、监听方式和连接地址示例。保存与完成单条编辑分开，切换配置和关闭窗口保护未保存草稿。
- 配置删除先迁移旧偏好，再保存配置目录状态，最后清理作用域；助手清理失败时恢复目录状态，文件删除在上述步骤成功后执行。
