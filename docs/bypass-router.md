# 旁路由检查与监控

本页是现有 TUN 能力的只读诊断页，不提供单独的旁路由启停开关，不修改 TUN、DNS、系统转发、NAT 或其他防火墙规则。设置仍在原有 TUN/DNS 页面操作。

## 检查内容

- 启动配置中显式设置的 TUN、Auto Route、Auto Redirect、DNS 监听、DNS 劫持和排除网段。缺失字段显示待验证，不拿界面默认值作为配置证据。
- Controller 返回的实际 TUN enable 状态，和启动配置分别展示。Controller 不可用时显示待验证。
- Linux 的 IPv4 转发状态和只读 nftables 规则摘要。工具缺失、权限不足和非 Linux 环境显示待验证。转发/NAT 数量不能证明具体链路放行，也不代表必须添加额外 NAT；未检查 iptables legacy 等其他防火墙实现。
- 当前 Mihomo 连接按局域网源 IP 汇总，排除 NAS 自身地址。只有 metadata.type 为 TUN 的连接才算 TUN 接管证据；HTTP/SOCKS 等显式代理流量不混为透明代理。流量值只累计当前仍存在的连接，不是设备全生命周期用量或速率。

每 10 秒刷新，可手动刷新。某一数据源失败不会阻止其他检查展示；失败来源的旧数据清除，避免把过期证据继续显示为当前状态。

## 验证设备

选择 NAS 接入网卡，按显示的 IPv4 和网段在设备侧配置网关。只有 NAS 已提供可达 DNS 服务时，设备 DNS 才指向 NAS。然后在设备上访问网站，观察是否出现该源 IP 的 TUN 连接、命中规则及出口链。

未看到连接可能是没有活动流量、连接已结束、源地址被 NAT 改写或未接管，不能据此认定不支持旁路由。已观察到某个 TUN 连接也不代表所有流量都被接管；IPv6、同网段通信和被排除的目的地址仍可能绕过。

此前未发布的控制版原型的系统写入、配置覆盖、设备策略编译、生命周期钩子及写 API 已移除。若曾手动运行该开发原型且仍留有 bypass-runtime.json，检查页只提醒使用旧构建停止恢复，不会自动处理该记录。

## 设备发现与会话记录

在 Linux 上只读执行 `ip -j -4 neigh show`，读取同网卡、同 IPv4 子网内、具有有效单播 MAC 的邻居记录。支持 REACHABLE、STALE、DELAY、PROBE、PERMANENT，过滤 FAILED/INCOMPLETE、NAS 本身和重复记录。此操作不主动扫描或发送探测包，不接管 DHCP。

设备表合并邻居记录与 Mihomo 连接。TUN 和显式代理证据来自当前连接，不沿用历史成功状态。邻居记录只标记“已发现”，不宣称在线或设置了 NAS 网关；MAC 不可获得时显示未知。

本页会话在内存中保留最近观察的设备（最多 256 个、24 小时）；页面内导航会保留，刷新浏览器清除。连接结束后清零当前连接及其流量，保留设备行。最近观察时间表示读到邻居记录或连接的时间，不是设备最后在线时间。IP 对应 MAC 改变时更新身份。邻居工具/权限不可用和连接 API 失败分别提示，旧流量不会继续显示为当前证据。

### 设备诊断与日志

点击设备的“查看详情”可查看其当前连接的目标、协议、入站、命中规则及出口链。出口按链的具体出口项显示为直连、规则拒绝、代理出口或待确认；命中代理不等于请求成功。

诊断区每 10 秒通过现有只读历史接口读取最近最多 200 条保留的 Controller 日志。设备范围仅匹配可识别的源端点（例如 `[TCP] IP:port --> ...` 或 DNS 的 `from IP:port`），不会把目标 IP 或其他设备的 IP 前缀当成所选设备。无来源的错误需要切换“查看全局日志”；全局日志不自动归属到所选设备。支持暂停刷新、警告/错误筛选、复制和导出当前显示内容。读取失败清空旧结果并提示错误；不修改 Core 或日志保存级别。

配置关注项与日志分开展示。IPv4 转发关闭提示 UDP/DNS 风险，但不直接判定设备故障。没有日志不代表没有故障，系统转发/防火墙处丢包可能完全不进入 Mihomo，必要时需抓包确认。基础配置与接入说明默认折叠，以设备观察和诊断为主。

设备列表默认隐藏标准 Docker 内部网桥（`docker数字`、`br-` 加 12 位十六进制标识），可勾选“显示容器网络”查看并诊断。顶部局域网 TUN 证据和接入网卡下拉始终排除这些网桥。按接口名称而非 `172.*` 等地址段区分，保留 `br0`、`br-lan`、bond、物理网卡及直接接入 LAN 的容器。非标准自定义 Docker 网桥名暂不自动识别；连接来源无邻居记录时按最具体匹配网段推断接口。

列表采用紧凑的设备 IP、观察结果、当前连接、当前连接累计流量及操作五列；MAC、网卡、最近观察、规则、连接明细与日志移至“查看详情”弹窗。关闭弹窗时卸载详情并停止日志请求；弹窗支持 Esc、关闭按钮和内部滚动。顶部状态与配置关注项以紧凑摘要展示。

设备弹窗顶部仅保留 MAC、网卡及最近观察。连接数量放在明细标题，移除重复的流量及规则/出口汇总；说明文字默认折叠，直连和拒绝出口不再重复显示同义链名称。
